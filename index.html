      삼성카드 승인 문자나 알림을 여러 개 한꺼번에 붙여넣어도 됩니다. 승인취소 문자는 해당 결제를 찾아 지워줍니다. 자동결제 문자와 후불교통 월 합계 문자(그 달 마지막 날로 기록)도 인식해요.

      PC·휴대폰 동기화

      내역을 나만 볼 수 있는 비공개 GitHub 저장소에 저장해서, 연결한 모든 기기가 같은 내역을 봐요. 기기마다 한 번씩 연결하면 돼요.

      1. 비공개 저장소 만들기 — 이름 ledger-data, Private 선택 (처음 한 번만)
      2. 토큰 만들기 — Repository access: Only select repositories → ledger-data, Permissions: Contents → Read and write
      3. 아래에 저장소와 토큰을 입력 (휴대폰에서도 같은 토큰을 쓰면 돼요)

      토큰은 이 기기의 브라우저에만 저장돼요. 기기를 잃어버리면 GitHub에서 토큰을 삭제하세요.
