# 캡처 안내 (PC 브라우저)

`endpoints.json` 을 만들려면 코레일 서버와 주고받는 내용이 필요하다.
**아이폰도 에뮬레이터도 필요 없다.** KTX·SRT 통합 예매는 PC 웹(`www.korail.com`,
구 letskorail.com 은 이쪽으로 넘어온다)에서도 되므로, 크롬 개발자도구로 기록하면 된다.

앱을 뜯을 때 필요한 인증서 설치나 피닝 우회가 전부 필요 없다. 이 길로 가는 이유다.

## 1. 기록 켜기

1. 크롬(엣지도 됨)에서 `www.korail.com` 접속 — **아직 로그인하지 말 것**
2. `F12` (맥은 `⌘⌥I`) → 위쪽 **Network** 탭
3. **Preserve log** 체크 — 페이지가 넘어가도 기록이 지워지지 않는다
4. 왼쪽 위 빨간 동그라미가 켜져 있는지 확인 (꺼져 있으면 눌러서 켠다)

## 2. 네 가지만 해보기

순서대로. 중간에 개발자도구를 닫지 말 것.

| # | 할 일 | 왜 |
|---|---|---|
| 1 | 로그인 | 로그인 요청의 필드 이름을 얻는다 |
| 2 | **좌석 남은 날** 조회 (평일 낮 아무 구간) | 조회 요청·응답 구조 |
| 3 | **같은 구간, 매진된 날** 조회 (주말 저녁 등) | 잔여석 필드가 "있음/없음"에 따라 어떻게 달라지는지 |
| 4 | 비인기 열차 하나를 **결제 직전까지** 예매 | 좌석 선점 요청 |

3번이 제일 중요하다. 조회를 한 번만 하면 어떤 값이 "자리 있음"인지 알 수 없다.

4번은 **실제로 좌석이 20분간 잡힌다.** 붐비지 않는 열차로 하고, 캡처가 끝나면
즉시 예매 취소할 것. 부담되면 4번은 건너뛰어도 된다 — 알림 전용으로는 동작한다.

## 3. 파일로 내보내기

Network 탭 목록에서 **우클릭 → Save all as HAR with content** → `korail.har` 로 저장.

## 4. 반드시 지우고 보내기

HAR 에는 **비밀번호와 세션 쿠키가 평문으로** 들어 있다. 그대로 공유하면 계정을 넘기는 것과 같다.

```bash
python3 scripts/scrub_har.py korail.har
```

`korail.scrubbed.har` 가 만들어진다. 이 스크립트는

- 비밀번호, 토큰, 쿠키, 아이디, 이름, 전화번호, 주민·카드번호의 **값**을 지운다
- 필드 **이름**과 열차 정보(역명, 열차명, 좌석 상태)는 남긴다 — 스펙을 만들려면 이게 필요하다
- 이미지·CSS 같은 군더더기와 코레일 외 도메인 요청을 버린다
- 남은 요청 목록을 화면에 출력한다 — **보내기 전에 직접 확인할 것**

출력 예시:

```
저장: korail.scrubbed.har  (3 KB)
남긴 요청 3개 / 버린 요청 3개 / 지운 값 12개

남은 요청 목록 — 보내기 전에 훑어보세요:
  POST 200      114B  https://www.korail.com/member/login
  POST 200      293B  https://www.korail.com/ticket/search/general
  POST 200      102B  https://www.korail.com/ticket/reserve
```

`korail.scrubbed.har` 만 공유한다. 원본 `korail.har` 는 공유하지 말고 지운다.

## 잘 안 될 때

| 증상 | 대처 |
|---|---|
| 요청이 수백 개라 못 찾겠다 | 그냥 다 저장하면 된다. 스크립트가 걸러낸다 |
| 로그인 요청이 안 보인다 | 이미 로그인된 상태다. 로그아웃하고 1번부터 다시 |
| `남은 요청이 없습니다` | `python3 scripts/scrub_har.py korail.har --all-hosts` |
| 조회가 `Fetch/XHR` 에 안 잡힌다 | 폼 전송식 사이트다. `Doc` 필터도 함께 볼 것 |
