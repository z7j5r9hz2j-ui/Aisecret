# 카카오톡 알림 설정

빈자리를 찾거나 좌석을 선점하면 **카카오톡 "나와의 채팅"** 으로 알림이 온다.
알림을 누르면 코레일 사이트가 열려 바로 결제할 수 있다. 선점된 좌석은 약 20분 안에
결제해야 하므로 이 경로가 짧을수록 좋다.

## MCP 카카오톡과는 다르다

Claude 에 연결된 카카오톡 MCP(`KakaotalkChat-MemoChat`)로는 이 알림을 보낼 수 없다.
MCP 도구는 **Claude 와 대화하는 동안에만** 동작한다. 반면 korail-watch 는 새벽 자정에
내 PC 에서 혼자 돌고 있고, 그때 Claude 는 관여하지 않는다.

그래서 프로그램이 **직접 호출할 수 있는** 카카오 API 를 쓴다. 최종적으로 메시지가
도착하는 곳은 같은 "나와의 채팅"이다.

## 1. 카카오 개발자 앱 만들기 (10분, 한 번만)

[developers.kakao.com](https://developers.kakao.com) 로그인 후:

1. **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름은 아무거나)
2. **앱 설정 → 앱 키** → `REST API 키` 복사
3. **제품 설정 → 카카오 로그인** → 활성화 **ON**
4. 같은 화면 **Redirect URI** 에 정확히 이 주소 등록:
   ```
   http://localhost:8910/callback
   ```
5. **카카오 로그인 → 동의항목** → `카카오톡 메시지 전송`(talk_message) 을 사용으로 설정

4번의 주소가 한 글자라도 다르면 5번 단계에서 실패한다.

## 2. 인증하고 저장하기

```bash
python3 scripts/kakao_setup.py --key 여기에REST_API_키
```

브라우저가 열리면 **동의하기** 한 번 누르면 끝이다.

```
브라우저에서 카카오 동의 화면을 엽니다. '동의하기' 를 눌러주세요.
토큰을 받았습니다.
테스트 메시지를 보냈습니다. 카카오톡 '나와의 채팅' 을 확인하세요.
.env 에 저장했습니다. 이제 GUI 를 켜면 알림이 함께 갑니다.
리프레시 토큰은 두 달마다 만료됩니다. 알림이 끊기면 이 명령을 다시 실행하세요.
```

동의 화면은 내 PC 의 `localhost:8910` 으로 돌아오고, 그 서버는 코드를 받는 즉시 닫힌다.
토큰은 `.env` 에 저장되며 이 파일은 본인만 읽을 수 있게(0600) 설정된다.

## 3. 토큰 만료

| 토큰 | 유효기간 | 처리 |
|---|---|---|
| 액세스 토큰 | 반나절 정도 | 자동 갱신. 6시간 감시 도중 만료돼도 알림이 끊기지 않는다 |
| 리프레시 토큰 | 두 달 | 만료되면 `kakao_setup.py` 재실행 |

갱신된 토큰은 `.env` 에 다시 저장되므로 다음 실행에도 이어진다.

## 텔레그램과 비교

| | 카카오톡 | 텔레그램 |
|---|---|---|
| 설정 시간 | 10~15분 (개발자 앱 등록 필요) | 2분 (BotFather) |
| 유지보수 | 두 달마다 재인증 | 없음 |
| 받는 곳 | 나와의 채팅 | 봇 대화방 |

둘 다 설정하면 양쪽으로 다 간다. 하나만 고른다면, 평소 쓰는 앱으로 고르는 게 맞다 —
새벽에 알림을 실제로 확인할 수 있는지가 전부다.

## 잘 안 될 때

| 증상 | 대처 |
|---|---|
| `토큰 발급 실패 ... Redirect URI` | 1-4 의 주소가 정확한지 확인 (`http`, 포트, `/callback`) |
| `8910 포트를 열지 못했습니다` | `--port 8911` 로 바꾸고 Redirect URI 도 같이 변경 |
| 브라우저가 안 열린다 | 화면에 출력된 주소를 직접 복사해 열면 된다 |
| 테스트는 왔는데 새벽에 못 받는다 | 폰 설정 → 카카오톡 → 배터리 → 제한 없음 |
| 알림이 어느 날 끊겼다 | 리프레시 토큰 만료. `kakao_setup.py` 재실행 |
