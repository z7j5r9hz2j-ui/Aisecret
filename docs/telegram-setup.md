# 텔레그램 알림 설정 (5분)

빈자리를 찾거나 좌석을 선점하면 폰으로 알림이 온다. 선점된 좌석은 **약 20분 안에
결제**해야 하므로, 알림을 놓치면 선점해도 소용이 없다. 그래서 이걸 먼저 해둔다.

세컨폰(안드로이드)을 알림·결제 전용기로 쓰면 좋다. 코레일+ 앱에 로그인하고
결제수단까지 등록한 채로 머리맡에 두면, 알림 오면 결제 버튼만 누르면 된다.

## 1. 봇 만들기

폰이든 PC든 텔레그램에서:

1. `@BotFather` 검색해서 대화 시작
2. `/newbot` 전송
3. 봇 이름 입력 (아무거나, 예: `코레일 알림`)
4. 사용자명 입력 — **반드시 `bot` 으로 끝나야 한다** (예: `my_korail_alert_bot`)
5. `Use this token to access the HTTP API:` 아래 나오는 **토큰**을 복사

토큰은 비밀번호와 같다. 남에게 주지 말 것.

## 2. 봇에게 먼저 말 걸기

**알림 받을 폰에서** 방금 만든 봇을 사용자명으로 검색해 대화를 열고,
아무 메시지나 보낸다 (`안녕` 등).

텔레그램 봇은 먼저 말을 걸 수 없다. 사용자가 한 번 보내야 봇이 답할 수 있다.
이 단계를 빼먹으면 다음 단계에서 chat_id 를 찾지 못한다.

## 3. 확인하고 저장하기

```bash
python3 scripts/telegram_setup.py --token 여기에토큰
```

```
봇 확인: @my_korail_bot (코레일알림)
chat_id 를 찾았습니다: 812345678 (세컨폰)
테스트 메시지를 보냈습니다. 폰을 확인하세요.
.env 에 저장했습니다. 이제 GUI 를 켜면 알림이 함께 갑니다.
```

폰이 울리면 끝이다. 토큰과 chat_id 는 `.env` 에 저장되므로 다음부터는 인자 없이
`python3 scripts/telegram_setup.py` 로 다시 확인할 수 있다.

## 4. 폰 설정 마무리

알림을 확실히 받으려면 세컨폰에서:

- 텔레그램 → 해당 봇 대화 → 알림 켜기, 소리 최대
- 안드로이드 설정 → 앱 → 텔레그램 → 배터리 → **제한 없음**
  (절전 모드가 새벽 알림을 늦추는 주범이다)
- 방해 금지 모드를 쓴다면 텔레그램을 예외로 등록

## 잘 안 될 때

| 메시지 | 대처 |
|---|---|
| `봇 토큰이 잘못되었습니다` | @BotFather → `/mybots` → 봇 선택 → API Token |
| `봇과 나눈 대화가 없습니다` | 2번을 빼먹었다. 폰에서 봇에게 메시지 먼저 보낼 것 |
| `여러 대화가 있습니다` | 출력된 목록에서 고른 뒤 `--chat-id 812345678` 추가 |
| 테스트는 왔는데 새벽에 못 받는다 | 4번의 배터리 제한 해제 |

알림 없이 쓰려면 아무것도 안 해도 된다. GUI 로그와 화면 알림만으로도 동작한다.
